# HANDOFFS — Passagem Formal entre Etapas do Projeto

## 1. Objetivo

A pasta `handoffs/` registra formalmente a transferência de responsabilidade,
dados, decisões, limitações e resultados entre as etapas do projeto.

Os handoffs devem impedir situações como:

```text
uma etapa terminar
↓
a próxima começar sem saber
qual versão usar
quais decisões já foram tomadas
quais problemas permanecem
quais resultados estão aprovados
