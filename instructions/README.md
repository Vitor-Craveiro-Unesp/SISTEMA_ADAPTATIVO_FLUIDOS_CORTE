# instructions/README.md — Instruções Operacionais do Projeto

## 1. Objetivo

Esta pasta contém as instruções oficiais de execução de cada etapa do projeto.

Cada integrante deve consultar primeiro este arquivo e, em seguida, a pasta
correspondente à sua responsabilidade.

A execução do projeto é sequencial.

Uma etapa somente deve ser considerada concluída após:

- execução dos procedimentos definidos;
- validação dos resultados;
- atualização do relatório da etapa;
- atualização do `STATUS.md`;
- aprovação no checkpoint correspondente;
- geração do handoff para o próximo responsável.
