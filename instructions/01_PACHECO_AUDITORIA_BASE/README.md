# 2. Objetivo da etapa

Realizar uma auditoria completa da planilha original antes de qualquer
classificação multicritério.

O objetivo é verificar se os dados fornecidos são:

- estruturalmente consistentes;
- numericamente corretos;
- completos;
- rastreáveis;
- adequados para análise estatística.

A etapa deve identificar e documentar problemas como:

- dados faltantes;
- valores pendentes;
- erros de fórmula;
- erros de soma;
- erros de média;
- diferenças numéricas entre abas;
- registros duplicados;
- fluidos ausentes;
- unidades inconsistentes;
- mistura de texto e número;
- valores suspeitos;
- valores impossíveis;
- variáveis constantes;
- inconsistências entre dados brutos e tabelas consolidadas.

Nenhuma correção deve ser feita silenciosamente.
