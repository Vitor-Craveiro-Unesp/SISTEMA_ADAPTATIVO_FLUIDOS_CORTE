# 2. Objetivo da etapa

Receber a base canônica aprovada e transformar a informação estatística
disponível em uma estrutura adequada para o problema de decisão multicritério.

Esta etapa deve:

- aprofundar a análise estatística;
- estudar relações entre variáveis;
- avaliar correlação e redundância;
- analisar conformidade técnica;
- distinguir critério de benefício, custo, alvo, restrição e diagnóstico;
- definir quais variáveis permanecem candidatas ao ranking;
- construir a matriz de decisão;
- definir a normalização;
- aplicar o método CRITIC;
- produzir pesos objetivos e justificáveis.

Nenhum ranking final deve ser produzido nesta etapa.
