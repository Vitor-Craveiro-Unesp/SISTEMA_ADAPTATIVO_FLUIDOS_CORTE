## 2. Objetivo

Realizar uma Análise de Dados inicial sobre a base canônica validada,
descrevendo o comportamento das variáveis e dos fluidos sem antecipar
a seleção definitiva dos critérios ou o ranking multicritério.

Esta etapa deve responder:

- como os dados se distribuem;
- quais variáveis apresentam maior ou menor variabilidade;
- quais fluidos apresentam comportamentos extremos;
- como as condições experimentais afetam os resultados;
- quais variáveis possuem pouca ou nenhuma capacidade discriminante;
- quais padrões ou anomalias merecem investigação posterior.

A ADA inicial deve ser descritiva e exploratória.
