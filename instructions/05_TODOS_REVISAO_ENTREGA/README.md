## 2. Objetivo

Realizar a validação final de todo o projeto antes da entrega.

Esta etapa deve garantir que:

- os dados utilizados são os dados aprovados;
- a análise pode ser reproduzida;
- os resultados são consistentes;
- o ranking final corresponde à versão oficial;
- relatório e apresentação utilizam os mesmos resultados;
- nenhuma análise preliminar permanece por engano;
- a documentação está completa;
- o repositório está organizado;
- a apresentação foi ensaiada;
- os arquivos de entrega foram conferidos;
- a versão final está congelada.
